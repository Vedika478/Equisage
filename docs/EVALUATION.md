# Evaluation Framework

To maintain the integrity of an evidence-first system, EquiSage requires rigorous evaluation at both the deterministic and probabilistic layers.

## 1. Deterministic Layer Tests

### Data Accuracy Tests
- **Objective:** Ensure Fetchers retrieve exact values from APIs without mutation.
- **Method:** Snapshot testing against known API responses.
- **Metric:** 100% exact match on raw data parsing.

### Calculation Accuracy Tests
- **Objective:** Ensure financial math (P/E, moving averages, relative valuation) is mathematically flawless.
- **Method:** Unit tests using hardcoded input matrices with known mathematical outputs.
- **Metric:** 100% precision up to required decimal places.

### Freshness Tests
- **Objective:** Ensure stale data is correctly flagged.
- **Method:** Inject time-delayed mock payloads and verify the `STALE` flag is raised.

## 2. Probabilistic Layer (AI) Tests

### Citation / Evidence Coverage
- **Objective:** Ensure every material claim generated by the AI Analyst links to the Evidence payload.
- **Method:** LLM-as-a-judge (or regex heuristics) scans the final dossier to ensure quantitative claims match the provided JSON payload.
- **Metric:** >98% citation coverage.

### Contradiction Detection
- **Objective:** Ensure the AI explicitly flags conflicting data.
- **Method:** Inject contradictory data (e.g., Bullish TA, Bearish Fundamentals) and evaluate if the "Conflicts" section of the dossier correctly surfaces the discrepancy.

### Hallucination Tests
- **Objective:** Catch the LLM inventing data.
- **Method:** Provide the AI with an explicitly sparse payload (`MISSING` fields). Evaluate the output to ensure the AI reports the data as missing rather than inventing numbers.
- **Metric:** 0 instances of hallucinated numbers.

### Point-in-Time Correctness
- **Objective:** Ensure the system does not leak future knowledge.
- **Method:** Run a historical payload (e.g., Q1 2024 data). The AI must only reference events and data up to that date.

## 3. Golden Datasets
We will maintain a "Golden Dataset" of 50 edge-case stock scenarios (e.g., missing data, extreme volatility, accounting scandals, conflicting signals). Every change to the AI prompts or architecture must run against this dataset to prevent regressions in research quality or hallucination rates.
